## 🚀 빠른 시작 방법

### 1단계: Supabase 테이블 생성
1. [Supabase 대시보드](https://supabase.com/dashboard)에 로그인하여 프로젝트를 선택합니다.
2. 좌측 메뉴의 **SQL Editor**로 이동합니다.
3. [`schema.sql`](file:///C:/Users/박태진/.gemini/antigravity/scratch/schema.sql) 파일의 내용을 복사하여 붙여넣고 **Run** 버튼을 실행합니다:

```sql
create table if not exists todos (
  id bigint generated by default as identity primary key,
  title text not null,
  is_completed boolean default false,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

alter table todos enable row level security;

create policy "Allow public access to todos" 
on todos for all 
using (true) 
with check (true);
```

### 2단계: 웹앱 실행 및 키 연동
1. 브라우저에서 [`index.html`](file:///C:/Users/박태진/.gemini/antigravity/scratch/index.html) 파일을 엽니다.
2. 우측 상단의 **⚙️ Supabase 설정** 버튼을 클릭합니다.
3. Supabase 대시보드의 **Project Settings ➔ API**에서 확인한:
   - **Project URL**
   - **Anon Public Key**  
   를 입력하고 **연결 및 저장**을 클릭합니다.

연결이 완료되면 상태 배너가 🟢 **Supabase 클라우드 데이터베이스에 연결됨**으로 변경되며 모든 데이터가 Supabase와 실시간 동기화됩니다.

## 🛠️ 기능 요약
- **Supabase Database (CRUD)**: 할 일 생성, 실시간 조회, 완료 토글, 삭제 지원
- **오프라인/로컬 모드 지원**: Supabase 키가 없어도 LocalStorage로 작동
- **보안 설정 (RLS)**: Row Level Security 정책 적용
- **반응형 UI**: 모바일 및 데스크톱 환경 지원
